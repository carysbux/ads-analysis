Global Ads Performance Dashboard

Spend, revenue, and efficiency across Google Ads, Meta Ads, and TikTok Ads

Introduction

This dashboard explores a synthetic global ads performance dataset: daily rows with platform, industry, campaign type, spend, revenue, and efficiency metrics. Charts are driven by dashboard/data.json, built from the cleaned tables in data/processed/.

Goals

• Compare cost efficiency (CPC and CPA) across Google Ads, Meta Ads, and TikTok Ads.

• See how revenue scales with spend, and where returns start to flatten.

• Identify the winning campaign type (best group ROAS) for each platform × industry.

Notes

  • The dataset is synthetic: patterns are useful for method, not for live bidding decisions.
  • Bin curves use ten quantile bins of ad spend within each platform.
  • ROAS winners can shift if spend mix by campaign type is uneven inside an industry.
